# Миссия 05 — Приёмка и релиз

**Ситуация.** Финал. Агент собирает витрину целиком и отчитывается:
«всё готово, всё работает». Ты уже знаешь цену этим словам. Слово агента
против твоих глаз — принимает человек.

**Задача.**

1. Попроси агента собрать финальную версию витрины по брифу и конституции.
2. Составь чек-лист приёмки из своего же брифа и Definition of done
   конституции (4–6 пунктов, каждый проверяем глазами).
3. Пройди чек-лист руками в браузере: каждый пункт — прошёл/провален и как
   проверял. Всё, что провалено, — верни агенту в форме «что сломано → как
   воспроизвести → что считается починенным». Запиши протокол приёмки в
   `project/docs/acceptance.md`.
4. После починки — пройди приёмку заново. Только когда все пункты прошли —
   объяви релиз: запись в `project/docs/decisions.md` («релиз v1, дата,
   что вошло»).

Совет: не спеши принимать. Первая сдача «всё готово» — проверь особенно
внимательно.

**Итог миссии:** витрина открыта в браузере и проходит твой чек-лист
целиком; протокол приёмки и запись о релизе — в `project/docs/`.

**Что проверяется** (для проверяющего):
- `project/docs/acceptance.md`: чек-лист из брифа/конституции, по каждому
  пункту вердикт и способ проверки; для возвратов — конкретика
- Запись о релизе в `project/docs/decisions.md`
- Финальная витрина соответствует чек-листу (сверь руками)
- Спец-протокол тренера по этой миссии — см. `drills/_trainer/keys.md`
