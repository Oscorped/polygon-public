# Задачка 08 — Сессия устала

Долгая рабочая сессия с агентом по витрине. В `drills/08-session/session-log.md` —
её фрагменты. Присмотрись: сессия деградирует. Это нормальная механика, а не
поломка: чем длиннее история, тем хуже агент в ней ориентируется, а после
нескольких сжатий начало теряется совсем. Злиться бесполезно — надо
управлять.

**Сделай** (надиктуй агенту — он сохранит в `journal/drills/08-handover.md`):

1. Выпиши симптомы деградации, которые нашёл в логе (цитата → что не так).
2. Прими решение: продолжать в этой сессии / сжать историю / начать новую.
   Одной строкой — почему.
3. Напиши **передаточное саммари** для новой сессии: принятые решения с
   причинами, текущий шаг, следующий шаг. Коротко — это выжимка, не
   пересказ переписки. Всё, чего в саммари нет, для новой сессии не
   существует.

**Проверка:** тренер «откроет новую сессию», где известно только твоё
саммари, и сам ответит на два контрольных вопроса по проекту, глядя только
в него. Если ответы из саммари следуют — передача сработала, зачёт. Симптомов в логе несколько,
тренер знает сколько.
