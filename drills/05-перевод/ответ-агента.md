# Ответ агента

Состояние заявок персистится в localStorage под ключом vitrina-bookings в
виде сериализованного массива объектов. При выборе окна значение пишется в
переменную chosen, а рендер списка дизейблит кнопки по множеству занятых
значений, которое пересобирается из стора на каждом рендере. Так как стор
браузерный и изолирован per-origin, синхронизации между клиентами нет:
конкурентный доступ двух пользовательских агентов к одному слоту не
детектируется, компенсирующая транзакция отсутствует. Для устранения гонки
потребуется серверная персистенция с уникальным констрейнтом на слот либо
оптимистическая блокировка с проверкой версии при коммите.
