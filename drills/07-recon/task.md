# Задачка 07 — Поставь параллельную разведку

Витрине нужны первые посетители. Каналов-кандидатов три: профильные
телеграм-каналы, партнёрства со смежными мастерами, платная реклама.
Разведку будут делать **три параллельных исполнителя** — по одному на
канал, каждый в чистой сессии, не видя работы других. Сам ресёрч проводить
не надо: эта задачка про постановку.

**Сделай** задание для исполнителей — надиктуй агенту, он сохранит в
`journal/drills/07-recon-brief.md`:

1. **Одинаковый для всех** список вопросов-критериев (4–6): без одинаковых
   вопросов сравнение потом не склеится.
2. Формат ответа каждого исполнителя (чтобы свелось в одну таблицу без
   переделки).
3. Формат итогового свода: таблица «каналы × критерии» + рекомендация
   отдельной строкой, отделённая от фактов.
4. Правило про неизвестное: что исполнитель пишет, когда данных нет
   (выдумывать нельзя — «нет данных» это тоже ответ).

**Проверка:** тренер сыграет роль одного из исполнителей и попробует
выполнить твоё задание «плохо, но формально правильно». Если формат этого
не позволяет — постановка крепкая, зачёт.
