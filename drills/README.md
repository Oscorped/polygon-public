# Тренажёр: десять задачек

Это не вопросы — это работа. Каждая задачка — реальная ситуация оператора
с настоящими артефактами: где-то подложен раздутый план, где-то агент
красиво врёт, где-то «готовая» страница не проходит приёмку. Твоя задача —
не рассказать, как надо, а **сделать**: переписать, разнести на ревью,
поймать, принять или завернуть.

Одна задачка — 5–15 минут. Проходи по порядку: скажи агенту
`начни тренировку` — он ведёт, проверяет и разбирает каждую сразу.

| # | Задачка | Навык |
| --- | --- | --- |
| 01 | Перепиши безнадёжный бриф | Постановка |
| 02 | Ответь как владелец | Уточнение |
| 03 | Разнеси план на ревью | План-ревью |
| 04 | Поймай агента на вранье | Контроль |
| 05 | Верни агента на язык продукта | Управление рамкой |
| 06 | Почини дырявую запись | Память проекта |
| 07 | Поставь параллельную разведку | Делегирование |
| 08 | Сессия устала | Гигиена контекста |
| 09 | Приёмка: найди, что сломано | Приёмка |
| 10 | Нарежь гору на слайсы | Поставка |

Заготовки к каждой задачке тренер показывает в чате целиком. Свой
результат просто напиши в чат — тренер сохранит его в `journal/drills/`
дословно и проверит. Файлы руками открывать и править не нужно.
